# 阶段入口自测（每阶段 15 分钟）

每个阶段开始前做对应的一组题。不用写答案，口头/动手能过就行。

**判定**：全对 → 该阶段压缩到 1 周或直接跳过；错 1–2 题 → 正常学，可跳过已掌握的 session；错 3 题以上 → 按计划完整学。

---

## Phase 1 入口自测（容器运行时进阶）

1. 说出 OCI 的三个 spec（image / runtime / distribution）各管什么（一句话 each）。
2. 一个 OCI 镜像的 manifest 里必须包含哪两类东西？（layers 列表 + config）
3. `runc spec` 生成的是什么文件？`runc run` 和 `docker run` 是什么关系？
4. 动手（2 分钟）：`ctr image pull docker.io/library/busybox:latest` 再 `ctr run` 跑起来（或用 docker 等价操作）。
5. 一句话说出 containerd / runc / docker 三者的分工。

## Phase 2 入口自测（Linux 隔离与安全原语）

1. `cat /sys/fs/cgroup/cgroup.controllers` 有输出说明什么？（cgroup v2 已挂载）
2. 动手（3 分钟）：建一个 cgroup 子目录，设 `memory.max=100M`，把当前 shell 的 PID 写进 `cgroup.procs`。
3. seccomp 是干什么的？（限制进程能用的 syscall，一句话）
4. 要让两个 netns 互通，说出需要的 3 个要素（veth 对、IP 地址、路由/bridge）。
5. overlayfs 里 lowerdir / upperdir / merged 各是什么？

## Phase 3 入口自测（虚拟化与轻量沙盒）

1. `/dev/kvm` 存在说明什么？（硬件虚拟化可用）
2. 一句话说出 KVM / QEMU / libvirt 三者的关系。
3. Firecracker 和普通 QEMU 虚拟机最大的区别是什么？（microVM：极简设备模型、毫秒级启动）
4. gVisor 的隔离靠什么？和 KVM 有什么本质区别？（用户态内核拦截 syscall，不是硬件虚拟化）
5. 动手（2 分钟）：进 Lima VM，`ls /dev/kvm` 确认存在。

## Phase 4 入口自测（编排与调度）

1. 从 `kubectl apply` 到容器跑起来，说出经过哪几个组件（apiserver → etcd → scheduler → kubelet → containerd → runc）。
2. CNI 是谁调的、什么时候调？（kubelet 通过 containerd 在创建 Pod 网络时调；IPAM 负责分配 IP）
3. `resources.requests` 和 `limits` 的区别（一句话）。
4. RuntimeClass 是干什么的？（给 Pod 选 runtime，如 kata / gvisor）
5. 动手（有环境才做）：`kubectl get nodes` 看到节点，跑一个 nginx pod 并 `kubectl logs` 看到输出。

## Phase 5 入口自测（Capstone 开工检查）

1. Phase 1–4 每个阶段你交付了什么？各用一句话说。
2. 纸上画出 mini-sandbox 的模块图（Runtime 抽象 / 镜像管理 / 网络 / 生命周期，5 分钟）。
3. "快照"在容器和 VM 下分别怎么做？（容器：overlay upper 层打包；VM：virsh 快照）
4. 并发跑 N 个沙盒任务，要考虑哪 3 个问题？（资源隔离、网络/端口冲突、日志归因）
5. 规划题：Capstone 的 6 个里程碑，先做哪两个？为什么？（没有标准答案，想清楚就行）
