# 学习方法：八步闭环

本项目采用八步学习闭环（整理自 AI 辅助学习方法论，见文末来源）。每一步在本仓库都有唯一对应的位置，不散落在各处。

| # | 步骤 | 在本仓库的位置 | 说明 |
|---|---|---|---|
| 1 | 提炼知识点 | `phase-*/知识点.md` | 每个 phase 要掌握的知识点清单，带前置依赖 |
| 2 | 规划学习路线 | `docs/学习路线.md` | 5 个 phase 的顺序、每个 session 的动手步骤 |
| 3 | 生成讲义 | `phase-*/README.md` | 每个 session 就是一节讲义：目标 → 动手 → 预期输出 |
| 4 | 播客 | `podcasts/` | 每 phase 一期对话播客，通勤/碎片时间听 |
| 5 | 学习反馈 | `docs/入口自测.md` + `phase-*/tests/TESTS.md` | 入口自测（15 分钟）+ 每条测试"操作 → 预期结果" |
| 6 | 总结、笔记本、错题本 | `phase-*/notes/` + `phase-*/mistakes/` | 笔记记"发生了什么"；错题本只收**真实踩过的报错** |
| 7 | 主线与支线 | `phase-*/知识点.md` 的"主线/支线"列 | 主线必修；支线可暂缓，不阻塞主线 |
| 8 | 学习报告 | `reports/` | 每个 phase 结束后一份：交付物、测试状态、错题统计 |

## 执行顺序（一个 phase 走一遍）

1. 做 `docs/入口自测.md` 对应阶段的 5 道题（15 分钟）→ 决定跳过哪些 session
2. 看 `phase-*/知识点.md`，确认主线有哪些、依赖关系
3. 按 `phase-*/README.md` 一个 session 一个 session 动手（25–40 分钟一节）
4. 卡住先查 `mistakes/错题本.md`，有新坑就记进去（只记真实报错原文）
5. 跑 `tests/TESTS.md`，操作 → 预期结果逐条过
6. 写 `reports/` 学习报告，归档本 phase

## 铁律

- **先做再看**：不预习，讲义里的"背景"不超过 5 行，动手先行。
- **一条命令 + 预期输出**：凡是"打开文档找 XX"的步骤，一律改成可复制命令 + 预期输出。
- **错题本不编造**：没在实机出现过的错误不写；每条按"看到什么 → 为什么 → 怎么修"组织。
- **支线不阻塞**：标为支线的 session/知识点可以跳过，主线不断就行。
