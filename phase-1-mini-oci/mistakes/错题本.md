# Phase 1 错题本

> 只收实机真实踩过的。每条：**看到什么 → 为什么 → 怎么修**。完整版散在各 session 的"常见坑"里，这里是复习用的精选。

## 1. `select {}` 程序直接 panic

- **看到什么**：`fatal error: all goroutines are asleep - deadlock!`，exit 2。
- **为什么**：`select {}` 作为唯一的 goroutine，Go runtime 的 deadlock 检测会干掉进程。
- **怎么修**：用信号等待（`signal.Notify` + `<-ch`）；`docker stop` 发的 SIGTERM 还能让它体面退出。
- **教训**：`select {}` ≠ `while true`。常驻等待用信号或 `time.Sleep` 循环。

## 2. heredoc 卡住，终端没有任何反应

- **看到什么**：`cat > file <<EOF` 回车后，终端卡住，后续命令都不执行，也没报错。
- **为什么**：收尾的 `EOF` 前面多了一个空格——它必须顶格（第 0 列）才算终结符；`<<-` 只剥 tab 不剥空格。
- **怎么修**：`Ctrl-C` 救出来；或手动敲一个顶格的 `EOF`。一劳永逸：用 `printf` 或编辑器写文件。
- **教训**：卡住时命令根本没执行，别以为文件写好了。

## 3. `docker: pull access denied for myimage`

- **看到什么**：`Error response from daemon: pull access denied for myimage, repository does not exist or may require 'docker login'`。
- **为什么**：九成不是登录问题。真正的信号是它上面那行 `Unable to find image 'myimage:1.0' locally`——本地没有才去 pull；Docker Hub 对"私有无权限"和"根本不存在"都返回 401，daemon 只能把两种原因用 or 拼起来。
- **怎么修**：回头查上一条命令（`skopeo copy` / `docker build`）为什么没成功，别去 `docker login`。
- **教训**：Docker 报错会骗人，先看**上一行**。

## 4. skopeo 连不上 Colima 的 docker

- **看到什么**：`failed to connect to the docker API at unix:///var/run/docker.sock`，下游还跟着 `writing blob: io: read/write on closed pipe`。
- **为什么**：Colima 的 socket 不在默认位置；skopeo 不读 docker context，`DOCKER_HOST` 环境变量也不管用。closed pipe 只是"daemon 连不上把管道关了"的下游症状。
- **怎么修**：`skopeo copy --dest-daemon-host "unix://$HOME/.colima/default/docker.sock" ...`（当源时用 `--src-daemon-host`）。
- **教训**：看到 closed pipe 先往上翻找 `failed to connect`，别去查 layer 格式。

## 5. `jq` 取值拿到 `null`，一路静默错下去

- **看到什么**：`cat x.digest` 输出 `null`，后续拼 URL 得到 `.../blobs/null`，`HTTP 000`。
- **为什么**：`jq -r '.layer[0].digest'`（少了个 s）不报错，退出码还是 0，只给一个 null。
- **怎么修**：用 `jq -er`（`-e` 让 null/false 变成非零退出码）；口诀：任何"取值"步骤之后，先 `cat` 一眼再用。
- **教训**：跟"Go 里丢掉 error"同一类坑——静默错误比报错更贵。

## 6. `os.ReadFile` 的 error 被丢掉，打出空 layer

- **看到什么**：`go run mk-layer.go` 输出 `size=1536`（远小于二进制体积）；直到 `docker run` 才炸：`exec /hello: exec format error`。
- **为什么**：`hello` 不存在时 `os.ReadFile` 返回空 slice，代码把 error 丢了，打出 0 字节的 `hello`。OCI 结构完全合法，`skopeo inspect` 照收。
- **怎么修**：每个 error 都接住；二次确认 `tar tvf work/layer.tar` 看 `hello` 那行大小。
- **教训**：Go 里丢掉 error 就是在给未来的自己埋雷。

## 7. 改了 layer 只改一处，引用全对不上

- **看到什么**：digest 校验失败 / 工具找不到 blob。
- **为什么**：digest 是内容寻址，`layer.tar` 变一个字节，`LAYER_DIGEST` → `CONFIG_DIGEST` → `MANIFEST_DIGEST` 整条链全变。
- **怎么修**：`rm -rf work/myimage`，a→b→c→d 原样重跑。别想着增量改。

## 8. `runc run -d` 报 `cannot allocate tty`

- **看到什么**：`cannot allocate tty if runc will detach without setting console socket`。
- **为什么**：`runc spec` 默认 `process.terminal: true`（要一个 TTY，接当前 `/dev/tty`），而 `-d` 说"我去后台了"——后台进程不可能占前台终端。
- **怎么修**：`sed -i 's/"terminal": true/"terminal": false/' config.json`；或给 `--console-socket`（containerd 就是这么干的）。
- **教训**：`docker run` 不带 `-i -t` 时 `Cmd` 是 sh 也拿不到 stdin，读到 EOF 立刻退出（看起来像"什么都没发生"）。

## 9. token 5 分钟过期，pull 到一半 401

- **看到什么**：`401` + `www-authenticate: …,error="invalid_token"`。
- **为什么**：换 token 的响应里 `expires_in: 300`，启动时拿一次用到死必然过期。
- **怎么修**：任何请求收到 401 就换一次 token 再重发。

## 10. `curl` 下 blob 得到 0 字节文件

- **看到什么**：下载"成功"了，文件却是 0 字节。
- **为什么**：`GET /v2/<repo>/blobs/<digest>` 返回 **307**，`location` 指向 CDN 带签名的临时地址；`curl` 默认不跟随重定向，不加 `-L` 保存到的是 0 字节的重定向响应体。
- **怎么修**：`curl -L`。Go 的 `http.Client` 默认跟随（最多 10 跳），所以代码里看不到这一步。

## 11. 真实镜像暴露的 unpack bug（`638aa50`）

- **看到什么**：`symlink bin/tar: file exists`。
- **为什么**：`python:3.12-alpine` 的 layer 2 把 `bin/tar` 从硬链接换成了符号链接——OCI 层叠加语义允许上层在同一路径换文件类型；单层镜像（busybox）永远暴露不了这个问题。
- **怎么修**：新建前 `Lstat + RemoveAll`（`prepareTarget`）；普通文件先 unlink 再 `O_CREATE|O_EXCL`——别对已存在的硬链接直接截断写，那会改到被链接的文件本体（`/bin/busybox` 的字节）。
- **教训**：拿真实多层镜像测，不要只用 busybox。

## 12. macOS tar 的 `._*` 伴生文件

- **看到什么**：`tar tvf` 里看到 `._hello`；解出来的 rootfs 多出一堆垃圾，条目数虚高。
- **为什么**：APFS 文件带扩展属性，macOS `tar` 默认把它们存成 AppleDouble `._*` 条目。
- **怎么修**：`COPYFILE_DISABLE=1 tar -cf layer.tar .`。
