# Phase 1 学习笔记

> 容器运行时进阶。完成于 2026-10-02。

## 一句话

容器运行时这层没有黑盒了：镜像是"四个结构体 + 一条引用链"，运行是"bundle 丢给 runc"，中间的分发、解包、叠层全部亲手写了一遍。

## 关键链条（背下来）

```
index.json → manifest → (config + layers)     # 引用链
layer.tar 变 → LAYER_DIGEST → CONFIG_DIGEST → MANIFEST_DIGEST 全变   # digest 链
docker → containerd → runc → 内核               # 调用链
```

## 三个"啊哈"时刻

1. **digest 是地址，tag 是名字**：blob 可以缓存（`os.Stat` 一次就行），tag 映射不能缓存——tag 是可变指针。
2. **whiteout 是"记一笔说删了"**：只读下层删不掉，上层用 `.wh.<name>` 表达删除。overlayfs 就是把这套搬进内核。
3. **`runc run` 退出后自动清理**：`runc delete` 报 `container does not exist` 不是错——前台跑完的容器已经不存在了。

## 交付物

mini-oci（Go）：`pull`（顺链拉 blob，token 401 重试，307 跟随，本地 index 自己造）→ `unpack`（解压叠层，whiteout/opaque，`prepareTarget` 防层间覆盖）→ `run`（拼 bundle 调 runc）。测试 T1-1~T1-3 通过。
