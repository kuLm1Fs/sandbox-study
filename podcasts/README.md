# 播客

每 phase 一期对话播客（两人对谈），用于通勤/碎片时间复习。

- 脚本（`.txt`）进仓库，可按脚本重新生成音频。
- 生成的 MP3 体积大，不进仓库（见 `.gitignore`），在聊天里直接发可播放链接。

| 期数 | 内容 | 脚本 | 时长 |
|---|---|---|---|
| E01 | Phase 1 复盘：容器运行时进阶 | [phase-1-播客脚本.txt](phase-1-播客脚本.txt) | 约 6 分钟 |
| E02 | Phase 2 复盘：Linux 隔离与安全原语 | [phase-2-播客脚本.txt](phase-2-播客脚本.txt) | 约 8 分钟 |
| 串讲 | Phase 1–5 全串联：从一个容器到沙盒平台（K8s 集群/节点/命名空间细讲） | [phase-串讲-播客脚本.txt](phase-串讲-播客脚本.txt) | 约 8 分钟 |

主持人：老陈 / 小林（固定搭配，每期沿用）。
